# Довідник для українців за кордоном

Статический сайт: страницы стран, журнал изменений, sitemap и RSS. Каждый день программа проверяет официальные страницы, а GitHub сам пересобирает и публикует сайт. Хостинг бесплатный.

## Запуск за 10 минут, без денег

1. Создай аккаунт на github.com и новый **публичный** репозиторий, например `ukr-guide`.
2. Загрузи в него все файлы этой папки (кнопка Add file, Upload files). Важно: папка `.github` должна попасть в репозиторий.
3. Settings, затем Pages, в поле Source выбери **GitHub Actions**.
4. Вкладка Actions, выбери workflow «Перевірка джерел і публікація», нажми Run workflow.
5. Через 1-2 минуты сайт откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/ukr-guide/`.

Дальше он обновляется сам каждый день. Если официальная страница изменилась, GitHub пришлёт письмо о новом Issue со списком ссылок.

## Что ты делаешь руками (это неизбежно)

Когда приходит Issue «Змінились офіційні джерела»:
1. Открой ссылки, прочитай, что изменилось.
2. Если факт на сайте устарел, поправь нужный файл в `data/countries/*.json` (кнопка карандаша на GitHub) и сохрани. Сайт пересоберётся сам.

Автоматически тексты не переписываются, потому что ошибка в правилах для людей навредит им и убьёт доверие к сайту. Правка занимает несколько минут.

## Как добавить страну

Скопируй `data/countries/cz.json` в новый файл, например `data/countries/sk.json`, поменяй `code`, `name_uk`, `summary` и источники, добавь код в `order` в `data/site.json`. Факты добавляй только такие, которые сам проверил на официальном сайте, с ссылкой и датой `checked`. Источники без `"verified": true` помечаются как неперевірені.

## Доход

- **Партнёрские ссылки** (SIM-карты, переводы, страховки): добавь в `data/site.json` в `affiliates` объекты `{"title": "...", "url": "https://...", "description": "...", "countries": ["pl"]}`. Они выводятся с пометкой и `rel="sponsored"`. Домен для этого не нужен. Проверь условия партнёрской программы.
- **Реклама Google AdSense**: подаётся заявка с собственным доменом (около 10-15 долларов в год) и возрастом от 18 лет. После одобрения впиши в `site.json` свой `adsense_client` вида `ca-pub-1234567890123456`.

## Локально

```
python build.py --out dist          # собрать сайт в dist/
python monitor.py                   # проверить официальные страницы
python -m pytest -q                 # тесты (pip install pytest)
```

Python 3.10+, других библиотек не нужно.

## Чего программа не умеет

- Не определяет, что именно изменилось на странице, только то, что изменился её текст. Мелкие правки (дата, баннер) тоже дают запись.
- Не проверяет качество фактов: за них отвечаешь ты.
- Не гарантирует трафик и доход.
