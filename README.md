# Довідник для українців за кордоном

Статический сайт: страницы стран, журнал изменений, sitemap и RSS. Каждый день программа проверяет официальные страницы, а GitHub сам пересобирает и публикует сайт. Хостинг бесплатный.

## Файлы

Все файлы лежат в корне, папок нет, кроме `.github/workflows/deploy.yml` (автозапуск).

- `build.py` собирает сайт, `monitor.py` проверяет официальные страницы
- `site.json` настройки сайта, `country_*.json` страницы стран
- `test_build.py`, `test_monitor.py` тесты
- `changes.json` и `links.json` создаются программой сами

## Что ты делаешь руками

Когда приходит Issue «Змінились офіційні джерела»:
1. Открой ссылки, прочитай, что изменилось.
2. Если факт на сайте устарел, поправь нужный `country_*.json` (кнопка с карандашом на GitHub) и сохрани. Сайт пересоберётся сам.

Автоматически тексты не переписываются, потому что ошибка в правилах для людей навредит им и убьёт доверие к сайту.

## Как добавить страну

Скопируй `country_cz.json` в новый файл, например `country_sk.json`, поменяй `code`, `name_uk`, `summary` и источники, добавь код в `order` в `site.json`. Факты добавляй только такие, которые сам проверил на официальном сайте, с ссылкой и датой `checked`. Источники без `"verified": true` помечаются как неперевірені.

## Доход

- **Партнёрские ссылки** (SIM-карты, переводы, страховки): добавь в `site.json` в `affiliates` объекты `{"title": "...", "url": "https://...", "description": "...", "countries": ["pl"]}`. Они выводятся с пометкой и `rel="sponsored"`. Домен для этого не нужен. Проверь условия партнёрской программы.
- **Реклама Google AdSense**: подаётся заявка с собственным доменом (около 10-15 долларов в год) и возрастом от 18 лет. После одобрения впиши в `site.json` свой `adsense_client` вида `ca-pub-1234567890123456`.

## Локально

```
python build.py --out dist          # собрать сайт в dist/
python monitor.py                   # проверить официальные страницы
python -m pytest -q                 # тесты (pip install pytest)
```

Python 3.10+, других библиотек не нужно.

## Чего программа не умеет

- Не определяет, что именно изменилось на странице, только то, что изменился её текст. Мелкие правки (дата, баннер) тоже дают запись.
- Не проверяет качество фактов: за них отвечаешь ты.
- Не гарантирует трафик и доход.
